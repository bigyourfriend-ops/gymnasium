# Ғани Мұратбаев атындағы гимназия — сайт

Сайт гимназии (с. Сарыкемер, Байзакский район, Жамбылская область): **https://gmonline.kz**

- Хостинг **ps.kz** (Plesk, PHP 8.2), база данных **MySQL** (`gmonlin1_site`), фото и PDF — в папке `uploads/media/` на хостинге.
- Код сайта хранится в этом репозитории GitHub. После каждого изменения в ветке `main` GitHub сам выгружает сайт на хостинг по FTP (Actions → «Выгрузка на gmonline.kz»).
- Два языка: қазақша / русский.
- Новости, объявления, расписание 1–11 классов (с режимом для ТВ), программы, фотогалерея, газета «Мұратбаев News» и книги (листаются как книга, загружаются из PDF), документы, контакты, частые вопросы, проекты.
- Регистрация и вход по почте и паролю, подтверждение почты, восстановление пароля. Пароли хранятся в базе только в зашифрованном виде (bcrypt).
- Администратор редактирует содержимое прямо на сайте.

## Структура

```
index.html             — страница сайта
config.js              — адрес сервера (api/)
assets/app.js          — логика сайта
assets/db.js           — связь сайта с сервером (api/)
assets/data.js         — содержимое по умолчанию (пока в базе ничего нет)
assets/help.js, director.js, prof.js — «Маған көмек керек», «Директорға хат», «Мамандықтар әлемі»
api/index.php          — сервер: вход, права, сохранение, загрузка файлов
api/inc/               — код сервера (tables.php — права на таблицы, rpc.php — функции, auth.php — вход и файлы, schema.php — таблицы MySQL)
api/install.php        — установщик (один раз): подключение базы и перенос данных
uploads/media/         — фото и PDF (только на хостинге, в GitHub их нет)
google/                — скрипт отчётов учителей для Google Диска
maintenance/           — страница «Сайт в разработке»
```

Пароль базы данных хранится только на хостинге — в файле `gm-config.php` (папка над `httpdocs`, иначе `httpdocs/api/data/`). В GitHub его нет.

## Установка на ps.kz (один раз)

1. В GitHub должны быть секреты `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD` (Settings → Secrets and variables → Actions). После изменения в `main` сайт выгрузится сам.
2. Панель ps.kz → «Почта»: создайте ящик `noreply@gmonline.kz` — с него сайт отправляет письма (подтверждение почты, восстановление пароля).
3. Откройте **https://gmonline.kz/api/install.php**:
   - шаг 1 — данные базы из панели («Базы данных»): сервер `localhost`, база `gmonlin1_site`, пользователь и пароль базы;
   - шаг 2 — файл `migration.json` (перенос из Supabase) или «начать с пустого сайта»;
   - шаг 3 — установщик сам скачает фото и PDF и закроется.
4. Панель ps.kz → «SSL/TLS-сертификаты»: сертификат Let's Encrypt и перенаправление с http на https.
5. Панель ps.kz → «Резервное копирование и восстановление» → «Расписание»: еженедельная полная копия (файлы + база).

Настройки сервера (почта, SMTP, обязательное подтверждение почты `confirm_email`) — в `gm-config.php`. Если письма не доходят: впишите в него SMTP ящика `noreply@gmonline.kz` (`smtp_host`, `smtp_port` 465, `smtp_user`, `smtp_pass`).

## Роли и пользователи

Права раздаются через **роли** («Әкімші панелі» → «Рөлдер»): галочками отмечается, какие разделы роль может редактировать. Есть роли «Әкімші / Администратор» (системная, все права), «Хатшы / Секретарь», «Мұғалім / Учитель», «Директор», «Психолог». Роль человеку выдаётся в «Пайдаланушылар». Права проверяет сервер, обойти их через браузер нельзя.

**Тип пользователя** (Оқушы / Ата-ана / Мұғалім) при регистрации не выбирается — его ставит администратор: «Пайдаланушылар» → «Өңдеу». Там же администратор меняет **ФИО, почту, класс и пароль**, подтверждает почту (если письмо не дошло) и удаляет пользователя.

«Мұғалім» = подтверждённый учитель: может загружать отчёты за четверти и достижения в свою папку на Google Диске. Папка выбирается по ФИО профиля (см. `google/README.md`). Подтверждённый учитель не может сам менять ФИО.

Первый администратор при пустой базе: впишите почту в таблицу `admin_emails` (phpMyAdmin), зарегистрируйтесь на сайте с этой почтой и подтвердите её — роль «Администратор» выдастся сама.

### 5. Отзывы и предложения (#feedback)
Родители, ученики и выпускники пишут **без регистрации**. Защита от шутников и спама:
- **Модерация.** Ничего не появляется на сайте, пока администратор не нажмёт «Жариялау» («Жеке кабинет» → «Пікірлер»).
- **Автофильтр.** Мат, оскорбления, ссылки, реклама, КАПС и «ааааааа» автоматически уходят в «Спам». Список слов лежит в таблице `feedback_badwords` (phpMyAdmin), его можно пополнять.
- **Лимит.** Не больше 1 отзыва в минуту, 3 в час и 10 в сутки с одного адреса. При массовой атаке — не больше 40 новых отзывов за 10 минут на весь сайт.
- **Защита от ботов.** Скрытое поле-ловушка, проверка «сколько будет 3 + 5», запрет отправки быстрее 5 секунд, отсечение повторов одного и того же текста.
- **Приватность.** IP-адрес не хранится, только его хэш. Контакт автора виден только администратору. Если автор снял галочку «Согласен на публикацию», отзыв можно только прочитать, опубликовать его нельзя.

Администратор может ответить на отзыв — ответ публикуется под ним как «Ответ гимназии».

### 6. «Маған көмек керек» — обращения о буллинге (#help)
Ученики пишут **анонимно и без входа**. После отправки получают код `GM-XXXX-XXXX`, по которому видят ответ психолога и могут дописать.
- **Кто читает:** только роли, у которых явно отмечено право «Обращения о буллинге (психолог)» — «Психолог» и (по решению школы) «Директор». Полный администратор сайта их **не видит**: проверка строгая и в базе, и на сайте.
- **Где читать:** «Басқару панелі» → «Өтініштер (буллинг)».
- **Приватность:** IP-адрес к обращению не привязывается (для антиспама хранится только хэш IP отдельно и удаляется через сутки); в базе лежит хэш кода, а не сам код.
- **Данные психолога, ящика доверия и срок ответа** — в начале файла `assets/help.js` (объект `CONF`).

### 7. «Директорға хат» — личная страница директора (#director)
Страница с фото, ФИО и обращением директора, часами приёма и формой письма. Писать можно без входа; можно анонимно.
- После отправки автор получает код `DR-XXXX-XXXX`: по нему видит ответ директора и может дописать. Если автор вошёл на сайт и письмо не анонимное — оно видно ему в блоке «Менің хаттарым» без кода.
- **Кто читает:** только роль с правом «director». Есть роль «Директор» (письма директору + обращения о буллинге + отзывы) — выдайте её директору в «Пайдаланушылар». У администратора сайта этого права **нет**: письма личные.
- **Где читать и отвечать:** «Басқару панелі» → «Директорға хаттар».
- **Часы приёма и обращение директора** — в «Баптаулар» (поля «Директордың сөзі» и «Қабылдау уақыты»). Фото и ФИО берутся из раздела «Әкімшілік».
- Антиспам: до 3 писем в час и 8 в сутки с одного адреса, ловушка для ботов; IP не хранится (только хэш, удаляется через сутки).

### 8. «Мамандықтар әлемі» — профориентация (#prof)
Для 10–11 классов. Открывается со страницы проекта «Мамандықтар әлемі» (блок «Кәсіптік бағдар құралдары») или по адресу `#prof`.
- **Тест** (36 утверждений, 6 типов по идее Голланда) → код типа, подходящие профессии и пары предметов ЕНТ.
- **Каталог профессий** с поиском, фильтром по типам и отметкой «профессии будущего»; звёздочкой — в избранное.
- **ЕНТ-навигатор**: 14 пар профильных предметов и группы образовательных программ (по univision.kz, 2026 — сверяйте каждый год).
- **Карьерный паспорт**: история тестов и избранное (для вошедших; гостям — только на устройстве).
- **Статистика** по классам — видят роли с правами help, director или users.
- Данные (вопросы, профессии, пары ЕНТ): `assets/prof-data.js`.

## Важно знать
- **Регистрация открыта для всех**, но обычный пользователь ничего не может изменить на сайте.
- **BilimClass** не даёт другим сайтам входа через свои учётные записи, поэтому входа через BilimClass на сайте нет (на главной осталась только ссылка на электронный журнал).
- **Загрузка файлов**: фото и PDF до 20 МБ (`api/.user.ini`). Если хостинг не принимает большие файлы — Plesk → PHP → `upload_max_filesize` и `post_max_size`.

## Резервные копии

1. **Хостинг ps.kz** — Plesk → «Резервное копирование и восстановление»: полная копия (база MySQL с пользователями, фото, PDF, код) по расписанию. Включите еженедельную.
2. **Вручную из админки** — «Әкімші панелі» → «Сақтық көшірме» → «Көшірмені жүктеп алу»: ZIP со всем содержимым сайта и всеми фото/PDF. Там же можно восстановить сайт из такого ZIP. Делайте раз в месяц и храните на компьютере и флешке.
3. **Код** — всегда в этом репозитории GitHub.

### Если пропало всё
1. Создайте базу MySQL в панели ps.kz, удалите старый `gm-config.php` и пройдите `https://gmonline.kz/api/install.php` («начать с пустого сайта»).
2. Назначьте себя администратором (см. «Роли и пользователи»).
3. «Әкімші панелі» → «Сақтық көшірме» → выберите ZIP-копию → «Қалпына келтіру»: вернутся содержимое, роли, фото и PDF.
4. Учётные записи из ручной копии не восстанавливаются — их возвращает копия хостинга (Plesk) или пользователи регистрируются заново.
