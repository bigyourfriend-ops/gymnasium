# Ғани Мұратбаев атындағы гимназия — сайт

Статический сайт гимназии (с. Сарыкемер, Байзакский район, Жамбылская область) на **GitHub Pages** с учётными записями и базой данных в **Supabase**.

- Два языка: қазақша / русский
- Новости, объявления, расписание уроков 1–11 классов, программы, фотогалерея, газета «Мұратбаев News» и книги (листаются как книга, загружаются из PDF), документы, контакты, частые вопросы
- Регистрация и вход по почте и паролю, подтверждение почты, восстановление пароля
- Кнопка «Войти через BilimClass» (ведёт на bilimclass.kz)
- Администратор редактирует содержимое прямо на сайте. Изменения сохраняются в Supabase, фото — в Supabase Storage

Пароли хранит Supabase Auth в зашифрованном виде (bcrypt). В репозитории GitHub нет ни паролей, ни почт пользователей.

## Структура

```
index.html            — страница
config.js             — адрес и публичный ключ Supabase (заполнить!)
assets/app.js         — логика сайта
assets/styles.css     — стили
assets/data.js        — содержимое по умолчанию (пока в базе ничего нет)
supabase/schema.sql   — таблицы, права доступа, хранилище фото
```

## Настройка (один раз)

### 1. Supabase
1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query**: вставьте весь `supabase/schema.sql` и нажмите **Run**.
3. **Authentication → URL Configuration**:
   - *Site URL*: `https://bigyourfriend-ops.github.io/gymnasium/`
   - *Redirect URLs*: добавьте `https://bigyourfriend-ops.github.io/gymnasium/**`
4. **Project Settings → API**: скопируйте *Project URL* и ключ *anon public* в `config.js`.
   Ключ **service_role** никогда не вставляйте в сайт и не публикуйте.

### 2. GitHub Pages
**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
Через 1–2 минуты сайт откроется по адресу `https://bigyourfriend-ops.github.io/gymnasium/`.

### 3. Роли и администратор
Права раздаются через **роли**. Администратор создаёт их сам в «Жеке кабинет» → «Рөлдер» и галочками отмечает, какие разделы роль может редактировать:
новости, мероприятия, фотогалерея, расписание, «О гимназии», кружки и достижения, электронные ресурсы, контакты и настройки, модерация отзывов, пользователи и роли.
Изначально есть три роли: «Әкімші / Администратор» (системная, все права), «Хатшы / Секретарь», «Мұғалім / Учитель». Их можно менять, можно добавлять новые (завуч, психолог и т. д.).
Роль конкретному человеку выдаётся в «Пайдаланушылар». Права проверяет база данных (RLS), поэтому обойти их через браузер нельзя.

Первый администратор назначается один раз в Supabase **SQL Editor**:
```sql
insert into public.admin_emails (email) values ('ваша@почта.kz') on conflict do nothing;
```
После этого зарегистрируйтесь на сайте с этой почтой и подтвердите её. Роль «Администратор» выдастся автоматически.

### 4. Жеке кабинет (страница профиля)
Адрес: `.../gymnasium/#profile`
- **Все пользователи:** фото профиля, ФИО, роль, класс, телефон, смена пароля, выход на всех устройствах.
- **Администратор** дополнительно видит:
  - «Басқару панелі»: число пользователей, новостей, мероприятий и фото, быстрые действия, дату последней публикации, распределение по ролям;
  - «Пайдаланушылар»: поиск, фильтр по ролям, назначение и снятие прав администратора (последнего администратора снять нельзя).

### 5. Отзывы и предложения (#feedback)
Родители, ученики и выпускники пишут **без регистрации**. Защита от шутников и спама:
- **Модерация.** Ничего не появляется на сайте, пока администратор не нажмёт «Жариялау» («Жеке кабинет» → «Пікірлер»).
- **Автофильтр.** Мат, оскорбления, ссылки, реклама, КАПС и «ааааааа» автоматически уходят в «Спам». Список слов лежит в таблице `feedback_badwords`, его можно пополнять.
- **Лимит.** Не больше 1 отзыва в минуту, 3 в час и 10 в сутки с одного адреса. При массовой атаке — не больше 40 новых отзывов за 10 минут на весь сайт.
- **Защита от ботов.** Скрытое поле-ловушка, проверка «сколько будет 3 + 5», запрет отправки быстрее 5 секунд, отсечение повторов одного и того же текста.
- **Приватность.** IP-адрес не хранится, только его хэш. Контакт автора виден только администратору. Если автор снял галочку «Согласен на публикацию», отзыв можно только прочитать, опубликовать его нельзя.

Администратор может ответить на отзыв — ответ публикуется под ним как «Ответ гимназии».

### 6. «Маған көмек керек» — обращения о буллинге (#help)
Ученики пишут **анонимно и без входа**. После отправки получают код `GM-XXXX-XXXX`, по которому видят ответ психолога и могут дописать.
- **Настройка базы (один раз):** Supabase → SQL Editor → вставьте весь `supabase/help.sql` → Run (уже применено к текущему проекту).
- **Кто читает:** только роли, у которых явно отмечено право «Обращения о буллинге (психолог)» — «Психолог» и (по решению школы) «Директор». Полный администратор сайта их **не видит**: проверка строгая и в базе, и на сайте.
- **Где читать:** «Басқару панелі» → «Өтініштер (буллинг)».
- **Приватность:** IP-адрес к обращению не привязывается (для антиспама хранится только хэш IP отдельно и удаляется через сутки); в базе лежит хэш кода, а не сам код.
- **Данные психолога, ящика доверия и срок ответа** — в начале файла `assets/help.js` (объект `CONF`).

### 7. «Директорға хат» — личная страница директора (#director)
Страница с фото, ФИО и обращением директора, часами приёма и формой письма. Писать можно без входа; можно анонимно.
- После отправки автор получает код `DR-XXXX-XXXX`: по нему видит ответ директора и может дописать. Если автор вошёл на сайт и письмо не анонимное — оно видно ему в блоке «Менің хаттарым» без кода.
- **Настройка базы (один раз):** Supabase → SQL Editor → `supabase/director.sql` → Run (уже применено к текущему проекту).
- **Кто читает:** только роль с правом «director». Файл создаёт роль «Директор» (письма директору + отзывы + новости) — выдайте её директору в «Пайдаланушылар». У администратора сайта этого права **нет**: письма личные.
- **Где читать и отвечать:** «Басқару панелі» → «Директорға хаттар».
- **Часы приёма и обращение директора** — в «Баптаулар» (поля «Директордың сөзі» и «Қабылдау уақыты»). Фото и ФИО берутся из раздела «Әкімшілік».
- Антиспам: до 3 писем в час и 8 в сутки с одного адреса, ловушка для ботов; IP не хранится (только хэш, удаляется через сутки).

### 8. «Мамандықтар әлемі» — профориентация (#prof)
Для 10–11 классов. Открывается со страницы проекта «Мамандықтар әлемі» (блок «Кәсіптік бағдар құралдары») или по адресу `#prof`.
- **Тест** (36 утверждений, 6 типов по идее Голланда) → код типа, подходящие профессии и пары предметов ЕНТ.
- **Каталог профессий** с поиском, фильтром по типам и отметкой «профессии будущего»; звёздочкой — в избранное.
- **ЕНТ-навигатор**: 14 пар профильных предметов и группы образовательных программ (по univision.kz, 2026 — сверяйте каждый год).
- **Карьерный паспорт**: история тестов и избранное (для вошедших; гостям — только на устройстве).
- **Статистика** по классам — видят роли с правами help, director или users.
- Данные (вопросы, профессии, пары ЕНТ): `assets/prof-data.js`. База: `supabase/prof.sql` (уже применено).

## Важно знать
- **Письма.** Встроенная почта Supabase на бесплатном тарифе отправляет лишь несколько писем в час. Для школы подключите свой SMTP (например, почту на домене школы): **Authentication → Emails → SMTP Settings**.
- **Кто может редактировать.** Только пользователи из таблицы `admins`. Добавлять и удалять их можно только через SQL Editor.
- **Регистрация открыта для всех**, но обычный пользователь ничего не может изменить на сайте. Список зарегистрированных виден администратору в «Жеке кабинет → Тіркелген пайдаланушылар».
- **BilimClass** не даёт другим сайтам входа через свои учётные записи, поэтому кнопка просто открывает bilimclass.kz.
- **Бесплатный проект Supabase** засыпает после 7 дней без активности. Если сайт давно не открывали, содержимое может загрузиться с задержкой или показаться версия по умолчанию. Разбудить проект можно в панели Supabase.

## Резервные копии

Сайт состоит из трёх частей: **код** (этот репозиторий GitHub), **база данных** и **файлы** (фото, PDF) в Supabase. Копии делаются двумя способами:

1. **Вручную из админки** — «Әкімші панелі» → «Сақтық көшірме» → «Көшірмені жүктеп алу». Скачивается ZIP со всем содержимым сайта и всеми фото/PDF. Там же можно восстановить сайт из такого ZIP. Делайте раз в месяц и храните на компьютере и флешке.
2. **Автоматически каждое воскресенье** — GitHub Actions → «Резервная копия сайта». Полная копия: база данных вместе с учётными записями, все файлы и код, в ZIP с паролем (AES-256, открывать 7-Zip или WinRAR). Хранится 90 дней в разделе Artifacts запуска.
   Один раз нужно добавить секреты в *Settings → Secrets and variables → Actions*:
   - `SUPABASE_DB_URL` — Supabase → **Connect** → *Session pooler* → URI, вместо `[YOUR-PASSWORD]` — пароль базы данных;
   - `BACKUP_PASSWORD` — пароль для архива (запишите его в надёжном месте: без него архив не открыть).

### Если пропало всё (новый проект Supabase)
1. Создайте новый проект Supabase, выполните `supabase/schema.sql` в SQL Editor.
2. Вставьте новый *Project URL* и ключ *anon public* в `config.js`.
3. Зарегистрируйтесь на сайте, назначьте себя администратором (см. раздел «Роли и администратор»).
4. «Әкімші панелі» → «Сақтық көшірме» → выберите ZIP-копию → «Қалпына келтіру»: вернутся всё содержимое, роли, фото и PDF (ссылки на фото исправятся сами).
5. Учётные записи остальных пользователей из ручной копии не восстанавливаются — им нужно зарегистрироваться заново. Полностью (вместе с пользователями) базу можно восстановить из еженедельной копии GitHub: файлы `database/*.sql` выполняются через `psql` в новом проекте — это лучше поручить специалисту.
