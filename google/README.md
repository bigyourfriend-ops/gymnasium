# Отчёты учителей → Google Диск

Учитель на сайте: **Жеке кабинет → «Есептер мен жетістіктер»** → выбирает «1-тоқсан … 4-тоқсан» или «Жетістіктер» → файлы сами попадают в его папку:

```
2026-2027 / <методобъединение> / <ФИО учителя> / 1 ТОҚСАН | 2 ТОҚСАН | 3 ТОҚСАН | 4 ТОҚСАН | ЖЕТІСТІКТЕР
```

Каждая загрузка записывается в таблицу **«Тапсыру журналы 2026-2027»** (лежит в папке года): дата, учитель, раздел, файл, ссылка.

## Установка (один раз, ~5 минут)

Делайте под тем Google-аккаунтом, который **владеет** папкой «2025-2026» (школьный аккаунт). Скрипт работает от имени этого аккаунта — если сделать под личной почтой, загрузка сломается, когда у неё заберут доступ.

1. Откройте <https://script.google.com> → **Новый проект**. Назовите его «Гимназия — есептер».
2. Удалите всё в файле `Код.gs` и вставьте целиком содержимое файла [`teacher-reports.gs`](teacher-reports.gs). Нажмите 💾 **Сохранить**.
3. Вверху в списке функций выберите **`setupNewYear`** → **Выполнить** → **Разрешить доступ** (выберите школьный аккаунт → «Дополнительно» → «Перейти к проекту» → «Разрешить»).
   - Скрипт создаст папку **«2026-2027»** рядом с «2025-2026» с теми же методобъединениями и учителями (у каждого 5 подпапок) и таблицу журнала.
   - Если внизу написано «Превышено время выполнения» или «запустите ещё раз» — просто нажмите **Выполнить** ещё раз, он продолжит с места остановки.
4. **Развернуть → Новое развертывание** → ⚙ **Веб-приложение**:
   - *Выполнять как*: **Я**
   - *У кого есть доступ*: **Все**
   - **Развернуть** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
5. На сайте: **Әкімші панелі → Баптаулар → «Google Drive скрипті»** → вставьте ссылку → **Сақтау** → **Жариялау**.
6. В редакторе скрипта выберите функцию **`setupFast`** → **Выполнить** → разрешите доступ. Скрипт начнёт обходить все папки и сохранит их «снимок» (если папок много — достроит его в фоне за несколько минут); дальше сайт открывает отчёты за 1–3 секунды, а снимок обновляется сам раз в час, после каждой загрузки с сайта и по кнопке «Жаңарту» (в фоне).

Готово.

## Кто может загружать и как выбирается папка
- Только пользователь сайта, которого **администратор** отметил «Мұғалім» (Әкімші панелі → Пайдаланушылар → «Изменить» → Түрі: Мұғалім). Сам себя учителем пользователь отметить не может.
- Папка выбирается **сама — по ФИО в профиле сайта**. ФИО должно совпадать с названием папки учителя на Диске (регистр, порядок слов, «ё/е» и казахские буквы не важны).
- Если ФИО не совпало — учитель видит «ФИО не совпадает с папкой». Администратор исправляет ФИО на сайте (там же, «Изменить»).
- Если на сайте два подтверждённых учителя с одинаковым ФИО — загрузка закрыта обоим, пока администратор не исправит.
- Подтверждённый учитель сам ФИО поменять не может (только администратор) — чтобы нельзя было «перейти» в чужую папку.

## Каждый новый учебный год (в августе–сентябре)
Откройте проект на script.google.com → функция **`setupNewYear`** → **Выполнить**. Появится папка нового года (например «2027-2028») с той же структурой и новый журнал; сайт сам начнёт класть файлы туда. Ссылку `/exec` менять не нужно.

## После переезда сайта на ps.kz (октябрь 2026)
Скрипт теперь проверяет учителя через сервер сайта `https://gmonline.kz/api/`, а не через Supabase. Нужно один раз обновить его:
**script.google.com → проект «Гимназия — есептер» → вставить новый `teacher-reports.gs` целиком → Сохранить → Развернуть → Управление развертываниями → ✏ → Версия: новая → Развернуть.** Ссылка `/exec` остаётся прежней.

## Если что-то не так
- **Нового учителя нет на Диске** — создайте в папке года (в его методобъединении) папку с его ФИО и подпапками 1 ТОҚСАН … 4 ТОҚСАН, ЖЕТІСТІКТЕР (или запустите `setupNewYear`, если его папка есть в прошлом году).
- **Новая папка видна не сразу** — список папок обновляется раз в 10 минут.
- **Изменили скрипт** — *Развернуть → Управление развертываниями → ✏ → Версия: новая → Развернуть* (ссылка остаётся той же).
- Один файл — до 25 МБ.
